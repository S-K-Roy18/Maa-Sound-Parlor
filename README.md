## 🪔 About

**माँ साउंड पार्लर — DUNIYA** is a creative web experience inspired by
the nostalgia of old Indian neighbourhoods, roadside shops, train journeys,
rooftops, childhood memories, and the 90s.

Instead of selecting a playlist, you select a **world**.

> **"आज कहाँ बैठोगे?"**

Each world combines:

- 🎬 Fullscreen background video/image
- 🎵 Curated YouTube playlist
- 🇮🇳 Nostalgic Indian atmosphere
- ✨ Cinematic transitions
- 🎨 Custom visual styling
- 🎧 Immersive music experience
